## 방법

1. 별책 12의 공통 교육과정 '음악' 중 초등학교 부분만 사용했다. 내용 체계표의 중학교 1~3학년 열, 선택 중심 교육과정 과목, 초→중 연결은 이 작업 범위 밖이다.
2. C계층은 `2. 내용 체계 및 성취기준 → 가. 내용 체계`의 연주·감상·창작 세 표에서 초등학교 3~4학년 열과 5~6학년 열이 같은 행에 놓인 내용 요소 쌍만 갈래로 인정하고, 각 내용 요소를 그 학년군·영역의 성취기준으로 전개했다.
3. D계층은 초등 두 학년군의 `(가) 성취기준 해설` 전체와 `(나) 성취기준 적용 시 고려 사항` 전체, 그리고 `1. 성격 및 목표`를 훑어 다른 성취기준의 선행 학습을 지목한 문장만 채택했다.
4. 코드는 모두 `data/kr/curriculum-standards.json`의 `kr-2022-elem-music` 목록(26개)에 존재하는지 대조했다.
5. 국가교육위원회 고시 제2024-3호 [별책12](`korean-secondary-learning-map/sources/official/text/kr-nec-2024-3-annex12.txt`)와 교차 확인했다. 초등 구간의 차이는 `문화유산 → 국가유산` 용어 교체뿐이며([4음02-05], [6음02-05] 문장과 감상 지식⋅이해 2행의 두 셀), 갈래 대응과 관계 구조는 동일하다. 인쇄 쪽수는 이 검토가 사용한 2022-33호판 기준이다.

## 쪽수 확인 방식

- 아래 `p.` 표기는 PDF 파일의 몇 번째 쪽인지가 아니라 별책 본문 하단에 인쇄된 쪽번호다.
- 추출 텍스트를 form feed(`\f`)로 분리한 뒤 각 페이지 하단의 쪽번호를 읽어 대조했다. 공통 교육과정 구간에서는 `PDF 쪽 번호 − 6 = 인쇄 쪽수`가 성립한다(예: PDF 14쪽 하단 = 인쇄 8쪽).
- 사용한 근거 쪽: 연주·감상 내용 체계표 p.8, 창작 내용 체계표 p.9, 3~4학년 연주 해설·고려 사항 p.10, 5~6학년 연주 고려 사항 p.14, 5~6학년 감상 고려 사항 p.15, 5~6학년 창작 고려 사항 p.17.

## 전개 규칙

1. **갈래 정의**: 한 영역·한 범주(지식⋅이해 / 과정⋅기능 / 가치⋅태도)의 내용 체계표에서 초등 3~4학년 열과 5~6학년 열이 같은 행에 놓인 내용 요소 쌍을 갈래로 본다. 음악과 세 영역은 모든 범주에서 두 학년군의 항목 수가 같아(연주 4/3/2, 감상 5/3/2, 창작 4/3/2) 행 정렬이 그대로 성립한다.
2. **성취기준 배정**: 성취기준 문장과 성취기준 해설의 문구가 내용 요소 문구와 일치하는지로 배정했다.
3. **중복 제거**: 한 갈래 쌍이 여러 범주에서 같은 코드 쌍을 만들면 1건으로 남기고 note에 근거 범주를 함께 적었다.
4. **결과 형태**: 배정 결과 세 영역 모두 학년군 안에서 성취기준 순번과 내용 요소가 나란히 대응하여, C계층은 `[4음NN-k] → [6음NN-k]` 대각선 13건이 되었다. 이는 코드 순서로 만든 것이 아니라 갈래 대응이 결과적으로 순번과 일치한 것이며, 아래 표에 갈래별 근거를 적는다.
5. **D계층 전개**: 지목 문장이 5~6학년 활동을 여럿 열거하면 그 활동을 실현하는 성취기준 모두로 전개한다. C계층과 같은 코드 쌍이 되는 전개는 중복을 피해 이 문서에만 기록했다.

### 다중 전개가 발생한 지점

- 5~6학년 창작 고려 사항(p.17) "3~4학년에서의 자유로운 발상을 토대로, 5~6학년에서는 … 떠올리며 표현하기, 바꾸거나 활용하여 만들기 등의 창작 활동을 통해"는 5~6학년 창작 과정⋅기능 3요소를 그대로 열거한다. 열거된 요소를 실현하는 [6음03-01]·[6음03-02]·[6음03-03]·[6음03-04] 넷으로 전개했고, 이 중 [4음03-01]→[6음03-01]은 C계층과 같은 쌍이라 D계층에서 제외해 3건이 되었다.
- 5~6학년 연주 고려 사항(p.14) "3~4학년에서 학습한 음악 요소, 주법과 표현 기법, 노래, 악기 연주 등"은 3~4학년 쪽에서 [4음01-01](자세와 주법, 노래·악기 연주)과 [4음01-02](음악 요소)로 갈라진다. 문장 후반이 지목한 5~6학년 목표("협력적인 음악 연주 활동을 통해 소통하며")는 [6음01-03]이므로 2건으로 전개했다.
- 5~6학년 감상 고려 사항(p.15) "3~4학년에서 학습한 음악 요소, 종류 등"은 [4음02-01](음악 요소)과 [4음02-03](다양한 종류의 음악)으로 갈라지고, 문장 후반이 지목한 "보다 전체적이고 조화로운 음악적 구성"은 [6음02-02]이므로 2건으로 전개했다.

- C계층 13건이 `[4음NN-k] → [6음NN-k]` 대각선이 된 것은 음악과 내용 체계표가 영역·범주마다 두 학년군 항목 수를 맞추어 놓았고 성취기준이 그 순서대로 진술되었기 때문이다. 코드 순서를 근거로 삼은 것이 아니며, 위 표의 갈래 열이 각 건의 실제 근거다.
- D계층 10건 중 3건은 같은 학년군(3~4학년 연주) 안의 지목이다. 계약이 같은 학년군 지목을 허용하므로 채택했으나, 튜터가 "먼저 알아야 한다"로 제시할 때 학년군 내 순서로 읽히도록 주의가 필요하다.
- [4음03-01] → [6음03-02]/[6음03-03]/[6음03-04] 3건은 한 문장에서 나온 확산 전개다. 문장이 5~6학년 창작 과정⋅기능 요소를 모두 열거하고 있어 채택했지만, 전문가 검토 시 범위를 좁힐 여지가 있다.
- note 문자열은 내용 요소 문구와 근거 요지를 짧게 적은 것이며 성취기준 원문이나 고려 사항 원문을 재수록하지 않았다.
