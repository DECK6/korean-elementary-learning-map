## 3. 방법

1. 내용 체계표 4개(영역별)를 그대로 옮겨 3~4학년군 / 5~6학년군 내용 요소를 범주별로 대조했다.
2. **도덕과 내용 체계표에는 이름이 붙은 내용 요소 행이 없다.** 과학·수학처럼 "같은 행이 학년군으로 진행"하는 구조가 아니라, 학년군마다 서로 다른 가치 질문·기능·태도를 나열한다. `pdftotext -layout` 출력에서도 3~4학년군 열과 5~6학년군 열의 불릿이 행 단위로 정렬되지 않는다(자신과의 관계 지식⋅이해는 3~4가 4개, 5~6이 3개로 개수부터 다르다). 그래서 표의 배치만으로는 "같은 갈래"를 읽어낼 수 없다.
3. 이를 보완하기 위해 아래 두 판정 기준만 사용했다. 둘 중 하나도 만족하지 못하면 채택하지 않았다.
   - **C-a (어휘 계열)**: 지식⋅이해 / 과정⋅기능 / 가치⋅태도 세 범주 중 **둘 이상**에서 같은 가치⋅주제 어휘가 3~4학년군과 5~6학년군에 이어져 나타날 것.
   - **C-b (핵심 아이디어 명시)**: 같은 내용 체계표의 핵심 아이디어 문장이 3~4학년군 내용 요소와 5~6학년군 내용 요소를 직접 기반⋅인과 관계로 서술할 것.
4. 성취기준 해설·적용 시 고려 사항은 문장 단위로 훑어 "~을 바탕으로", "~을 주제로", "~을 확장하여"처럼 다른 성취기준의 내용을 선행으로 지목한 문장만 D계층으로 옮겼다.

## 4. 내용 요소 → 성취기준 전개 규칙

초등 도덕은 **영역·학년군별 지식⋅이해 내용 요소 개수와 성취기준 개수가 정확히 1:1로 일치한다.**

| 영역 | 3~4 내용 요소 / 성취기준 | 5~6 내용 요소 / 성취기준 |
| --- | --- | --- |
| 자신과의 관계 | 4 / 4 | 3 / 3 |
| 타인과의 관계 | 3 / 3 | 3 / 3 |
| 사회⋅공동체와의 관계 | 3 / 3 | 4 / 4 |
| 자연과의 관계 | 2 / 2 | 2 / 2 |
| 합계 | 12 / 12 | 12 / 12 |

따라서 내용 요소 하나는 성취기준 하나로만 전개되며, **다중 전개(한 내용 요소 → 여러 코드)는 발생하지 않는다.** 과정⋅기능·가치⋅태도 범주의 불릿도 같은 순서로 지식⋅이해 불릿과 짝을 이룬다(예: 자연과의 관계 3~4는 생명 / 공생 두 갈래가 세 범주에서 모두 같은 순서로 반복된다).

D계층에서 한 근거 문장이 같은 주제의 3~4학년군·5~6학년군 성취기준을 함께 지목하면 두 코드에서 각각 간선을 낸다(통일 → 인류애, 생명 경시 사례·환경 위기 → 지속가능한 삶).

## 8. 한계

- 도덕과 내용 체계표는 명명된 내용 요소 행이 없어 C계층 판정에 3절 규약을 그대로 기계 적용할 수 없다. 본 검토는 어휘 계열(C-a)·핵심 아이디어 명시(C-b)라는 대체 판정 기준을 정의해 사용했고, 그 기준은 위 4·3절에 재현 가능하도록 적었다. 다른 판단자가 기준을 조정하면 C1(성실→반성, 2범주로 하한을 겨우 만족)과 C5·C6(핵심 아이디어 근거)이 가장 먼저 흔들릴 수 있다.
- C-b는 핵심 아이디어 문장을 근거로 쓰므로 엄밀히는 내용 요소 행의 진행이 아니라 표 머리글의 진술이다. 자연과의 관계에는 세 범주 어디에도 학년군을 잇는 공통 어휘가 없어 이 근거 없이는 해당 영역의 C계층이 0건이 된다는 점을 밝혀 둔다.
- 도덕과 성취기준 본문은 저작권 정책상 재수록하지 않고 내용 요소 문구와 고려 사항의 핵심 어구만 인용했다.
- 초→중 연결(예: [6도01-*] → [9도01-*])과 교과 간 연결은 이 작업 범위 밖이므로 다루지 않았다.
