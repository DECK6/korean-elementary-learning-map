## 3. C계층이 0건인 이유

통합교과 내용 체계표는 네 과목 모두 내용 요소 칸이 **초등학교 1~2학년** 한 열뿐이다. 인접 학년군 진행(1~2 → 3~4)이 문서 안에 존재하지 않으므로 `contentSystemRequired`는 0건이며, 이는 결측이 아니라 교과 구조상 정상이다.

[2바04-04] 고려 사항의 "1~2학년군에서 배운 것을 친구들과 되돌아보며 **3학년 이후 교과 교육과 연계**할 수 있다"와 [2슬04-04] 고려 사항의 "주제학습을 성찰하면서 **3학년 이후 교과 교육**에 대한 기대감을 형성할" 역시 교과 간·학년군 간 연결이라 채굴 대상이 아니다.

## 6. 전개 규칙

1. **범위**: 2026판 ‘건강한 생활’ 고려 사항의 ‘연계’ 항목에서 통합교과 내부 코드(바·슬·건·즐)를 지목한 문장만 대상으로 삼았다. 국어과 [2국02-01]·[2국05-03], 수학과 [2수01-01]·[2수02-01]·[2수03-03], 체육과 [4체01-04]·[4체02-02]·[4체02-03]·[4체02-04]·[4체02-08]·[4체03-01]·[4체03-02]를 지목한 문장은 교과 간 연결이라 전부 제외했다.
2. **방향 판정**: 서술어로 결정한다. "…와 연계하여 〈이 성취기준의 내용〉을 …하도록 지도할 수 있다"는 *지목된 코드 → 건 코드*, "〈이 성취기준의 경험〉을 …으로 확장하도록 지도할 수 있다"는 *건 코드 → 지목된 코드*로 전개한다. 어느 쪽이 선행인지 서술어로 판정할 수 없으면 채택하지 않았다(7절 D-후보 참조).
3. **코드 의미 검증**: 2026판 근거 문장이 지목한 코드는 저장소 인벤토리와 성취기준 문장이 같아야 전개한다. 바·슬은 두 판이 동일해 통과, 즐은 전면 재배정이라 전부 탈락, [2즐02-06]은 저장소 인벤토리에 아예 없다.
4. **다중 지목**: 한 근거 문장이 통합교과 코드를 둘 이상 지목하면 각각 별도 간선으로 낸다([2건02-05] 문장은 D6·D7 두 방향을 함께 담는다).
5. 통합교과 성취기준은 코드 하나에 문장 하나가 1:1로 대응하므로 내용 요소 → 코드 다중 전개는 발생하지 않는다.

## 8. 한계

- **official 간선 9건 전부가 2026-1 일부개정판 근거인데 모듈 `sourceId`는 2022판이다.** 계약이 모듈당 sourceId 하나만 허용하므로 지시대로 2022판을 유지하고 `note`·`printedPage`에 2026판 출처를 실었다. 빌더가 `sourceRefs`/`sourceLocator`를 성취기준별 `sourceRefs`에서 다시 채우거나, 계약을 확장해 튜플 단위 sourceId를 허용하면 이 불일치를 없앨 수 있다.
- 채택 근거는 모두 "연계 … 지도할 수 있다"형 문장이다. 통합교과는 네 과목을 하나의 주제로 통합 운영하므로 이 연계가 **동시 학습**일 수도 있다. 서술어가 방향을 드러내는 문장만 골랐지만(6절 규칙 2), 선수 관계로서의 강도는 다른 교과의 "~에서 학습한"류 근거보다 약하다는 점을 밝혀 둔다. 특히 D1·D3·D9는 근거 문장이 "강조할 수 있다/자극할 수 있다"로 끝나 방향은 분명하되 필수성은 약하다.
- 즐거운 생활 코드가 두 판 사이에서 전면 재배정되었으므로, 저장소 인벤토리가 2026판으로 갱신되면 이 모듈의 제외 판단(7절 2·3행)을 반드시 재검토해야 한다. 재갱신 시 [2즐01-03] → [2건03-01], [2즐02-06] → [2건03-02] 2건이 추가 후보가 된다.
- 2022판·2026판 성취기준 본문은 코드 대조 목적으로만 사용했고 대량 재수록은 하지 않았다.

## 10. 즐거운 생활 연계 채굴 (2026-09-05 범위 확장)

9.4절이 별도 과제로 남긴 ‘즐거운 생활’ 절 채굴을 수행했다. 모듈 D계층은 11건 → **27건**이 되었고, `expansionRules` 두 번째·세 번째 항목의 범위·방향 규칙을 이에 맞추어 갱신했다. 1~9절은 그대로 보존한다.

### 10.1 범위와 원문 확인

| 항목 | 값 |
| --- | --- |
| 대상 절 | 2026-1 별책15 ‘즐거운 생활’ **성취기준 적용 시 고려 사항 → ‘연계’ 항목** |
| 인쇄 쪽 | 63~78 (즐 성취기준 16개가 각 1쪽) |
| 근거 문서 | `kr-ncic-2026-1-annex15-pdf` (모듈 `sourceId`와 동일) |
| 쪽수 확인 | `pdftotext -layout` 출력을 form feed(`\f`)로 잘라 각 페이지 마지막 줄의 쪽번호로 확정. 이 문서에서는 인쇄 쪽 N = 텍스트 페이지 인덱스 N+5 |

**9.4절의 합계 “23건”은 오기다.** 원문을 다시 스캔한 결과 즐 절 ‘연계’ 항목이 지목한 통합교과 코드는 **21건**이다(9.4절 표의 16개 행에 적힌 코드를 그대로 세면 2+1+1+2+1+1+1+1+2+1+2+1+1+1+2+1 = 21). 표의 행 내용 자체는 원문과 일치하며 합계 숫자만 틀렸다.

```bash
python3 - <<'PY'
import re
txt = open('<2026판 별책15 pdftotext 출력>', encoding='utf-8').read()
for i, page in enumerate(txt.split('\f')):
    if 68 <= i <= 83:                      # 인쇄 p.63~78

        print(i - 5, re.findall(r'\[2[바슬건]\d{2}[-‐-―−]\d{2}\]', flat))
PY
# 63 ['[2바02-04]', '[2슬02-04]'] … 78 ['[2바02-03]']  → 합계 21
```

### 10.2 방향 판정 규칙 (6절 규칙 2의 정밀화)

‘연계’ 문장은 항상 **대상 성취기준의 고려 사항 안에** 놓이고, 지목된 코드를 그 수업에 끌어들이는 형식이다. 방향은 **주 서술어가 내놓는 결과가 어느 성취기준의 학습 내용인지**로 판정한다.

| 유형 | 문장 형태 | 판정 | 선례 |
| --- | --- | --- | --- |
| **F (정방향)** | “〈지목 코드〉와 연계하여 … 〈대상 코드의 내용〉을 …하도록 할 수 있다” — 지목 코드는 맥락⋅소재⋅수단⋅태도 자원 | 지목 코드 → 대상 코드 | D1~D6, D8~D11 |
| **R (역방향)** | “〈대상 코드의 경험〉을 〈지목 코드의 개념〉**으로 확장**하도록 …” — 방향성 서술어와 도달점이 모두 명시 | 대상 코드 → 지목 코드 | D7 |
| **X (미판정)** | 지목 코드의 내용이 문장의 **전제와 결과 양쪽**에 나타나 순환하거나, 지목 코드의 기능이 대상 코드의 소재에 적용되기만 하고 선후 표지가 없음 | 채택하지 않음 | 7절 `[2바04-04]` ↔ `[2건01-02]` |
