## 방법

1. 내용 체계표(인쇄 p.6~12)에서 5개 영역(운동과 에너지, 물질, 생명, 지구와 우주, 과학과 사회)의 `지식⋅이해` 범주 갈래 행을 모두 추출하고, 각 행의 `초등학교 3~4학년군` 열과 `초등학교 5~6학년군` 열 내용 요소를 정리했다.

4. 성취기준 해설(가)과 성취기준 적용 시 고려 사항(나)을 인쇄 p.13~39 전 구간에서 훑어, 초등 선행 학습 내용을 특정해 지목한 문장만 D계층으로 채택했다.

## 전개 규칙 요약

- C계층 대상은 내용 체계표 `지식⋅이해` 범주의 갈래 행이며, 같은 행의 초등 3~4학년군 열과 초등 5~6학년군 열 사이에서만 짝을 만든다.
- 두 열 중 하나가 비어 있는 갈래(열, 물질의 변화, 물질의 구조, 항상성과 몸의 조절, 생명의 연속성, 환경과 생태계, 생명과학과 인간의 생활, 과학과 안전, 과학과 진로)는 0건으로 둔다.
- 내용 요소 쌍은 두 요소가 같은 대상·현상을 가리키거나, 3~4학년군 요소가 5~6학년군 요소의 관찰·분류 단계에 해당할 때만 채택한다.
- 내용 요소 → 성취기준 코드 전개는 그 학년군·영역에서 해당 요소를 직접 다루는 성취기준 전부로 하며, 한 요소가 여러 성취기준에 걸치면 각각을 별도 쌍으로 전개한다(예: 지구의 대기 → `[6과06-01]`, `[6과06-02]`, `[6과06-03]`).
- 한 성취기준이 두 갈래 행의 요소를 동시에 담당하면(예: `[4과02-01]`은 '동물의 생김새'와 '특징에 따른 동물 분류'에 모두 걸린다) 짝을 만든 쪽 갈래의 의미로 해석하고 note에 그 요소 이름을 남긴다.
- C계층과 D계층이 같은 코드 쌍을 지시하면 내용 체계표 근거를 우선해 C계층에만 넣는다.

## 검토했지만 채택하지 않은 후보

### 1. 단원 목록만 나열하는 "…와 연계된다" 항목 (12개 5~6학년군 단원)

각 단원의 '성취기준 적용 시 고려 사항' 첫 항목은 관련 단원을 나열한다. 5~6학년군 단원에서 3~4학년군 단원을 지목하는 경우는 다음 12건이다.

- 지층과 화석 ← 땅의 변화 (p.26)
- 우리 몸의 구조와 기능 ← 동물의 생활, 생물의 한살이 (p.28)
- 혼합물의 분리 ← 물체와 물질 (p.29)
- 날씨와 우리 생활 ← 지구와 바다 (p.30)
- 열과 우리 생활 ← 물의 상태 변화 (p.31)
- 산과 염기 ← 물체와 물질 (p.33)
- 물체의 운동 ← 힘과 우리 생활 (p.34)
- 식물의 구조와 기능 ← 식물의 생활, 생물의 한살이 (p.35)
- 지구의 운동 ← 밤하늘 관찰 (p.36)
- 계절의 변화 ← 밤하늘 관찰 (p.36)
- 물질의 연소 ← 물체와 물질, 여러 가지 기체 (p.37)
- 전기의 이용 ← 자석의 이용 (p.38)

채택하지 않은 이유: (1) "연계된다"는 선후가 아니라 상호 관련을 뜻하는 진술이고, 같은 문장이 후속 학교급인 중학교 단원과 같은 학년군 단원까지 함께 나열한다. (2) 진술 단위가 단원이어서 성취기준 수준으로 옮기면 단원 × 단원 교차곱(약 160쌍)이 되어, 원문이 말하지 않은 개별 성취기준 사이의 필수 선수 관계를 만들어낸다(예: `[4과11-04]` 지진 대처 → `[6과01-03]` 화석의 가치). (3) 5~6학년군 사이의 상호 지목(용해와 용액 ↔ 혼합물의 분리, 지구의 운동 ↔ 계절의 변화, 산과 염기 ↔ 물질의 연소)은 방향이 없어 그대로 쓰면 사이클이 된다.
다만 위 12건 중 8건은 C계층에서 독립적으로 채택한 쌍과 같은 단원 조합이어서, C계층 선택을 뒷받침하는 방증으로만 사용했다.

### 2. 같은 갈래 행이지만 서로 다른 현상인 쌍

- 빛과 파동 행: 3~4학년군은 소리(소리의 발생·세기·높낮이·전달), 5~6학년군은 빛(직진·반사·굴절·렌즈)만 다룬다. 두 현상 사이에 요소 수준의 계승이 없어 0건으로 두었다.
- 힘과 에너지 행의 무게·수평잡기·도구의 이용: 5~6학년군 열에 대응 요소가 없다.
- 유체 지구 행의 바다의 특징·밀물과 썰물·파도·바닷가 주변 지형·갯벌 보전: 5~6학년군 열이 모두 대기 현상이라 대응 요소가 없다.
- 천체 행의 달의 모양과 표면·달의 위상변화·태양계 행성: 5~6학년군 열에 달·행성 요소가 없다(중학교 열에 다시 등장한다).
- 고체 지구 행의 화산 활동·지진 대처 방법: 5~6학년군 열에 대응 요소가 없다.

### 3. 영역이 다른 진행

물의 상태 변화(물질) → 열과 우리 생활(운동과 에너지), 물체와 물질(물질의 성질) → 산과 염기(물질의 변화), 생물의 한살이(생명의 연속성) → 우리 몸의 구조와 기능(생물의 구조와 에너지)은 단원 연계 항목이 지목하지만 내용 체계표에서 갈래 행이 다르다. C계층 규칙이 같은 행만 허용하므로 채택하지 않았다.

### 4. 같은 학년군 안의 진행

5~6학년군 안의 진행(예: 용해와 용액 → 혼합물의 분리, 지구의 운동 → 계절의 변화)은 학년군 경계를 넘지 않으므로 C계층 대상이 아니고, 이를 지목하는 문장도 선후가 아닌 상호 연계 진술이어서 D계층으로도 채택하지 않았다.

## 한계

- 이 검토는 저장소 내부의 공식 문서 대조 결과이며 과학 교과 전문가의 승인 기록이 아니다(`reviewStatus`는 `internal-reviewed` 수준).
- 내용 요소 → 성취기준 전개는 성취기준 문장과 해설을 읽고 판정한 것으로, 별책이 요소별 대응표를 제시하지는 않는다. 요소가 두 성취기준에 걸치는 경우(혼합물의 분리 등)의 선택 근거는 위 표에 남겼다.
- note는 원문을 재현하지 않은 짧은 의역이며, 저작권 정책에 따라 성취기준·해설 본문을 재수록하지 않았다.
- 인쇄 쪽수는 `pdftotext -layout` 결과의 페이지 하단 쪽번호로 확인했다. 추출 과정에서 단어 내부 공백이 생기는 구간이 있어 코드 검색은 정규식으로 재확인했다.
