# 초등 인용 고시 판 ↔ 현행 판 차이 조사 (2026-09)

조사일: 2026-09-05
대상: `data/kr/curriculum-standards.json`의 11개 교육과정 / 620개 성취기준 코드
요약 매트릭스: `docs/source-version-matrix.md`

> 본 문서는 조사 보고서다. `data/`, `schema/`, `scripts/`, `ontology/` 는 일절 수정하지 않았고 커밋도 하지 않았다.
> 저장소의 `textPolicy`를 따라 고시 원문 문장은 재수록하지 않는다. 성취기준은 **코드 + 변경/동일 판정**으로만 표기하고, 내용 체계는 표의 셀 명칭(내용 요소 명칭) 수준까지만 적는다.

> **적용 상태 (2026-09-05)**: 이 조사의 P0·P1 권고는 저장소에 반영되었다. 통합교과는 2026-1판 별책15 단일 기준으로 재작성했고(별책2 2026-1판을 교차검증 출처로 추가), 음악은 2024-3호 별책12(10003999), 실과는 첨부 10004244로 재핀했다. 갭 3건을 종결하고 신규 갭 3건을 기록했다. P2 권고(사회 별책7 → 10003993, 영어 별책14 → 10004085)는 초등 무영향이므로 이번 반영 범위에서 제외했다. 변경 내역은 저장소 `CHANGELOG.md`와 `PROVENANCE.md` "인용 판 이력"에 있다.

## 1. 방법

### 1.1 자료 수집

1. 초등 저장소가 인용하는 NCIC 첨부를 `sourceUrls`에 적힌 URL 그대로 재다운로드했다.
   - 엔드포인트: `https://ncic.re.kr/inv/org/download.do?year=<연도>&seq=<첨부번호>&orgType=ogi4`
   - 저장 위치: 세션 스크래치패드 `ncic/elem-verify/`
   - 요청 간격 2초 이상, 일반 브라우저 User-Agent 사용
2. 내려받은 파일의 SHA-256을 `data/kr/curriculum-standards.json` `sources[].sha256` 및 `scripts/lib/kr-source-provenance.mjs`의 `OFFICIAL_PDF_SOURCE_SNAPSHOTS` 값과 대조했다.
3. 현행 판은 중등 저장소 캐시(`/Volumes/data/Dev/korean-secondary-learning-map/sources/official/files|text/`)를 사용했다. 캐시 파일의 SHA-256을 `source-receipts.json` 기재값과 재대조하여 무결성을 확인한 뒤 사용했다.
4. 텍스트 추출은 전 파일 `pdftotext -layout -enc UTF-8`.

### 1.3 비교 알고리즘

- **코드 집합**: 정규식 `\[(\d{1,2}[가-힣]+\d{2}[-–]\d{2})\]`로 문서 전체에서 코드 토큰을 수집하고, 대시류(U+2010~U+2015, U+2212 등)를 ASCII `-`로 정규화했다. 초등 코드는 선행 숫자가 2·4·6인 것으로 한정했다.
- **성취기준 문장**: 줄 첫머리가 `[코드]`로 시작하는 항목만 성취기준 목록 항목으로 인정하고(불릿 `•`·`∙`으로 시작하는 성취기준 해설·연계 문단은 제외), 들여쓴 후속 줄을 이어 붙여 한 문장으로 복원했다. 이후 NFKC 정규화 → 모든 공백 제거 → 대시 정규화 후 문자열 비교했다.
  - 위양성 통제: `[4미03-03]`, `[4체02-04]`처럼 "연계" 문단의 줄바꿈 때문에 줄 첫머리에 나타난 교차참조는 육안으로 원문 위치를 확인해 위양성으로 판정, 결과에서 제외했다.
- **내용 체계표**: `pdftotext -layout` 결과의 내용 체계 절을 직접 대조하고, 셀의 `⋅`/`∙`/`ㆍ` 불릿 토큰(내용 요소 명칭)을 집합 비교했다.
- **전체 문서 회귀 확인**: 각 별책에 대해 줄 단위 정규화(NFKC, 공백 제거, 대시 정규화, 쪽번호 줄 제거) 후 `diff`를 돌려, 위 구조적 비교가 놓친 변경이 초등 구간(문서에서 `[9…]` 코드가 처음 나오기 전 구간)에 있는지 교차검증했다.

### 1.4 교차검증 자료

교과별 별책 비교와 별개로, **[별책2] 초등학교 교육과정**(초등 전 교과를 한 문서에 수록) 2022판 ↔ 2026판을 같은 방식으로 비교해 결과를 교차검증했다. 두 경로의 결론은 완전히 일치한다.

### 3.6 과학 [별책9]

- 인용 URL(`seq=10003551`)이 반환하는 파일의 SHA-256 `0cf53427…`은 중등 저장소가 `kr-nec-2024-3-annex9`(첨부 10004171)로 기록한 파일과 **바이트 단위로 동일**하다.
- 정규화 diff 결과 **0줄**. 초등 102개 코드 전부 동일.
- 문서 표지에는 「교육부 고시 제2022-33호 [별책 9]」만 적혀 있고 2024-3호 일부개정 표기가 없다. 즉 NCIC가 같은 파일을 두 첨부번호로 게시했을 뿐 과학과 교육과정 본문에는 개정이 없다. 두 저장소의 라벨이 서로 다른 것은 표기 문제일 뿐 내용 문제는 아니다.

### 5.1 현행 데이터셋이 안고 있는 실제 오류

`kr-2022-elem-integrated`는 2022판 48개 + 2026판 건강한 생활 9개를 섞은 하이브리드다(`scripts/lib/kr-source-provenance.mjs`의 `OFFICIAL_INVENTORY_GATES['kr-2022-elem-integrated']`가 `sourceGroups`로 이 혼합을 명시적으로 허용하고 있다). 그 결과:

1. **유령 코드 4개**: `[2즐04-01]`~`[2즐04-04]`가 남아 있으나 현행 고시본에 존재하지 않는다.
2. **누락 코드 4개**: `[2즐02-05]` `[2즐02-06]` `[2즐03-05]` `[2즐03-06]`이 없다.
3. **의미 불일치 12개**: `[2즐01-01]`~`[2즐03-04]`의 `summary` 값이 2022판 성취기준을 요약한 것이어서, 현행 고시본이 같은 코드에 부여한 성취기준과 내용이 전혀 다르다. 예컨대 `[2즐01-01]`의 요약은 놀이·건강·안전 취지이나 현행 `[2즐01-01]`은 소리 탐색 취지다.
4. **코드 총계 우연 일치**: 57 = 57이라 `standardCount` 게이트는 통과한다. 개수 검증만으로는 이 오류를 잡을 수 없다.

이 4번 때문에, 코드 개수 대신 **코드 집합 + 문장 지문 대조**를 게이트에 추가하지 않으면 같은 오류가 재발한다.

### 8.3 재핀 시 반드시 함께 결정할 정책 사항

1. **"현행 고시본" vs "현재 시행 중인 판"**: 2026-1호 별책15의 초등 시행일은 2028-03-01이다. 학습지도용 데이터가 어느 쪽을 기준으로 하는지 명시하지 않으면, 2027학년도까지는 데이터와 현장이 어긋난다. 두 판을 모두 보존하되 `effectiveFrom` 같은 필드로 구분하는 편이 안전하다.
2. **코드 재사용 문제의 항구적 대응**: 통합교과처럼 같은 코드가 다른 성취기준으로 재배정되는 사례가 실재하므로, 소스 재핀 시 코드 존재 검사만이 아니라 **문장 지문(정규화 해시) 대조**를 게이트에 넣을 것을 권고한다.
3. **NCIC 첨부번호의 불안정성**: 과학(10003551 파일 교체), 실과(10003781 → 10004244) 모두 첨부번호·파일이 조용히 바뀐 사례다. `attachmentNo` 고정 인용만으로는 현행성을 보장할 수 없으므로, NCIC 인벤토리 트리 API로 "해당 교과 행의 현재 첨부"를 주기적으로 재조회하는 점검을 권고한다.

## 9. 재현 절차

```bash
# 1) 인용본 재다운로드 (요청 간 2초 간격)
curl -L "https://ncic.re.kr/inv/org/download.do?year=2022&seq=10003800&orgType=ogi4" -o annex7-social.pdf
#   ... 10003551(과학) 10003561(음악) 10003794(영어) 10003571(통합2022) 동일

# 2) 현행본
curl -L "https://ncic.re.kr/inv/org/download.do?year=2026&seq=10004214&orgType=ogi4" -o annex15-2026.pdf
curl -L "https://ncic.re.kr/inv/org/download.do?year=2022&seq=10004244&orgType=ogi4" -o annex10-current.pdf
curl -L "https://ncic.re.kr/inv/org/download.do?year=2026&seq=10004180&orgType=ogi4" -o annex2-2026.pdf

# 3) 해시 대조 및 텍스트 추출
shasum -a 256 *.pdf
pdftotext -layout -enc UTF-8 <in.pdf> <out.txt>

# 4) NCIC 인벤토리 트리 조회 (목록 확인)
curl -X POST https://ncic.re.kr/api/inv/inventoryNodeList.do \
  -H "X-Requested-With: XMLHttpRequest" -H "Referer: https://ncic.re.kr/inv/org/list.do" \
  -d "type=ogi4&nowTblType=org&menuType=1&invDepth=3&degreeCode=1014&classCode=1002&openYear=2026&openMonth=01&isAdmin=0"

# 5) 해당 행의 첨부 목록 (ref 값은 invDepth=4 조회로 획득)
curl -X POST https://ncic.re.kr/api/inv/invFileList.do \
  -H "X-Requested-With: XMLHttpRequest" -H "Referer: https://ncic.re.kr/inv/org/list.do" \
  -d "invSeq=<ref>&invYear=2026&orgType=ogi4&degreeCode=1014&classCode=1002&openYear=2026&openMonth=01&subjectCode=1100&nationCode=&type=org"
```

성취기준 추출·비교에 사용한 파이썬 스크립트는 세션 스크래치패드(`ncic/extract.py`, `ncic/compare.py`, `ncic/coverage.py`, `ncic/norm.py`)에 있으며 저장소에는 포함하지 않았다.
