# 초등 학습지도 인용 고시 판 × 현행 판 대조 매트릭스

- 조사일: 2026-09-05
- 조사 대상: `data/kr/curriculum-standards.json` `sources[]` 및 각 교육과정 `sourceUrls`가 인용하는 NCIC 첨부
- 검증 방법 요약: 인용 URL 재다운로드 → SHA-256 대조 → `pdftotext -layout -enc UTF-8` 추출 → 현행 판과 코드/문장/내용 체계 비교
- 상세 절차와 근거는 `docs/source-version-diff-2026-09.md` 참조
- **이 문서는 조사 보고이며, 데이터·스키마·스크립트는 변경하지 않았다.**

> **적용 상태 (2026-09-05)**: 이 조사의 P0·P1 권고는 저장소에 반영되었다. 통합교과는 2026-1판 별책15 단일 기준으로 재작성했고(별책2 2026-1판을 교차검증 출처로 추가), 음악은 2024-3호 별책12(10003999), 실과는 첨부 10004244로 재핀했다. 갭 3건을 종결하고 신규 갭 3건을 기록했다. P2 권고(사회 별책7 → 10003993, 영어 별책14 → 10004085)는 초등 무영향이므로 이번 반영 범위에서 제외했다. 변경 내역은 저장소 `CHANGELOG.md`와 `PROVENANCE.md` "인용 판 이력"에 있다.

## 6. 시행일 유의

국가교육위원회 고시 제2026-1호 부칙: 고등학교 1·2학년 2026-03-01, 고등학교 3학년 2027-03-01, **초등학교 1·2학년 2028-03-01**.
따라서 별책15 2026판은 2028학년도부터 초등 1~2학년에 시행되며, 그 이전 학년도의 현장 시행판은 2022-33호 별책15다. 재핀 시 "현행 고시본"과 "현재 시행 중인 판"을 구분해 표기해야 한다.
